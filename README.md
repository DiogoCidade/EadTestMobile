# Agorá — protótipo web inspirado em plataformas de comunidades

Projeto acadêmico (React + TypeScript + Vite) para demonstrar componentização.
Todos os dados são fictícios e ficam em `src/data/`. Não há backend.

## Executar (Windows / PowerShell)
```powershell
npm install
npm run dev
```
Abra http://localhost:5173

Outros comandos: `npm run build` (verifica tipos e gera build) · `npm run lint`.

## Funcionalidades
Pesquisa por título/conteúdo · ordenação Recentes/Populares · voto positivo/negativo
(clicar de novo desfaz) · salvar publicações · navegação entre Início, Popular, Comunidades,
Salvas e Histórico · filtro por comunidade · criar publicação (modal) · menu de perfil ·
layout responsivo (3 colunas → 2 colunas → menu em gaveta).

## Apenas demonstrativo
Perfil/Configurações/Sair não fazem nada; "Compartilhar" só copia um link fictício;
"Histórico" mostra as publicações em que você votou; publicações criadas somem ao recarregar.
